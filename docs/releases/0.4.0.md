## What's new

- **Maven builds.** The new `airgap-maven-extension` adds the agent to every module's Surefire, Failsafe,
  `spring-boot:run` and `exec:exec` runs, without editing any pom. It keeps the `argLine` a module already sets, such
  as JaCoCo's. Name it in `.mvn/extensions.xml` to keep it, or try it for one run with
  [`airgap-mvn.sh`](https://github.com/fiftiesHousewife/under-test-airgap/blob/main/tools/try-it/airgap-mvn.sh) in
  place of `mvn`. Each run's report goes to `target/airgap/<plugin>-<execution>/calls.jsonl`, and Maven names each
  report with calls in it as the build ends. Tests that run inside Maven's own JVM (`forkCount=0`) and `exec:java`
  are warned about, since the agent can't reach them this way.
- **Tests are named under Surefire's own JUnit 4 runner.** `airgap-junit` has a JUnit 4 listener, which the Maven
  extension registers, so the report names the test behind each call for JUnit 3 and 4 tests too, not only on the
  JUnit Platform.
- **Writes outside the project are reported.** Writing, deleting, renaming or moving a file, or making a folder,
  outside the build's root, the temporary folder and the folders `write_folders` lists in `testing/airgap.yaml`, is
  reported. Set `file_writes: refuse` to refuse them too; a refused write fails as a read-only file would.
- **Name your own packages in `testing/airgap.yaml`** (`packages: [com.example.]`), so each report line names your
  code's line, not a library's, however the agent is started.
- **`process:` entries take `*`,** as `native:` entries do (`process:redis-server-*`), and the summary lists a
  program unpacked under a new random name each run once.

## Proved

- The Maven extension is proved by sample builds on the latest Maven 3.6, 3.8, 3.9 and 4, including one with its own
  `argLine` and JaCoCo, a multi-module one, one with Maven 3.6's old default Surefire, and one named in
  `.mvn/extensions.xml`.
- Real Maven projects' tests give the same results under the extension as without it, apart from calls the agent
  should refuse: Spring PetClinic (with JaCoCo), Spring's getting-started guides, jsoup 1.11.3 and Apache Commons Net
  3.6.
- Real Gradle projects' tests give the same results with the file-write hooks as without them: Spring PetClinic, the
  RealWorld example app and Halo.
